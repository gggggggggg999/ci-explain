# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Use GitHub's private vulnerability reporting: open the repository's
**Security** tab and choose **Report a vulnerability**. Include the version,
a minimal synthetic reproduction, and the impact. Do not include real secrets
or private logs.

This is a single-maintainer open-source project; there is no guaranteed
response time, but reports are taken seriously.

## Supported versions

Only the latest released version receives fixes.

See [docs/SECURITY.md](docs/SECURITY.md) for the threat model.
