# Security model

How to report a vulnerability: see [SECURITY.md](../SECURITY.md) (GitHub private vulnerability reporting).

## Threat model

| Threat                                                             | Mitigation                                                                                                                                                                                                                                                                                                      | Remaining risk                                                                                                                                                    |
| ------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Untrusted logs** (a pull request author controls log content)    | Logs are only parsed as text. Nothing from a log is executed, interpolated into a shell, or used as an instruction. Suggested commands are shown as text.                                                                                                                                                       | Parsing bugs. Fuzz-like tests exist but are not exhaustive.                                                                                                       |
| **ReDoS**                                                          | Lines are truncated (default 2000 chars) before any regex runs; rules use anchored/simple patterns and substring checks; tests throw pathological lines at normalization, every rule, and redaction under a time limit.                                                                                         | A new rule with a bad regex; reviewers and the pathological-input test are the guard.                                                                             |
| **Huge or hostile input**                                          | `--max-bytes` keeps memory bounded (the end of an oversized log is analyzed); binary input is tolerated with a warning; there is no archive extraction.                                                                                                                                                         | Memory is several times the input size (see DECISIONS D-008).                                                                                                     |
| **Secret leakage**                                                 | Redaction before analysis and output; counts only; a second pass over AI prompts; excerpts always redacted.                                                                                                                                                                                                     | Pattern-based redaction can miss secrets (see PRIVACY.md).                                                                                                        |
| **Prompt injection** (log text addressed to an AI)                 | Instructions and log are separate messages; the log sits inside fixed markers that the log cannot forge; the model must answer in a strict JSON shape validated by Zod; anything else is discarded; the model has no tools. Output is stripped of HTML, links, images and mentions and shown as untrusted text. | A prompt cannot eliminate prompt-injection risk. The model can still be misled into a wrong explanation, which is why it is labeled "AI-generated, may be wrong". |
| **Unsafe Markdown / PR comments**                                  | Prose is escaped; `@mentions`, `#123` and autolinks are neutralized; evidence is fenced with a fence longer than any backtick run in the content; output is capped below 1 MiB with a visible note.                                                                                                             | Renderers may treat Markdown differently; the GitHub job summary was the target.                                                                                  |
| **SSRF / key leakage via `--llm-base-url` and `--github-api-url`** | These URLs are chosen by the user, so the tool announces the destination on stderr, requires https (http only for localhost), rejects URLs with credentials, never follows redirects for the AI key, and handles GitHub redirects manually so the token never goes to another host.                             | A malicious URL **you** pass receives your key or token. Only use hosts you trust.                                                                                |
| **Credentials in process lists / shell history**                   | `GITHUB_TOKEN` and `CI_EXPLAIN_LLM_API_KEY` are read from the environment only; there is no flag for them.                                                                                                                                                                                                      | Environment variables are visible to same-user processes.                                                                                                         |
| **Supply chain**                                                   | One runtime dependency (`zod`), exact versions pinned in the lockfile, `npm audit` and Dependabot, CI with minimal permissions and actions pinned to commit SHAs.                                                                                                                                               | Transitive and dev-dependency compromise cannot be excluded.                                                                                                      |
| **Overwriting files**                                              | `--export-excerpt` refuses to overwrite without `--force` and creates files with mode 0600.                                                                                                                                                                                                                     | —                                                                                                                                                                 |

Not implemented on purpose: telemetry, auto-updates, executing suggestions, plugins, user-supplied rule files.
