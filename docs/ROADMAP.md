# Roadmap

Ideas only. Nothing here is implemented or promised.

- More rules, driven by community requests (Go, Rust, Java/Gradle/Maven, .NET, Ruby, PHP).
- Native step parsing for other CI systems (GitLab CI, Jenkins, CircleCI), each only after real fixtures and tests exist.
- A set of real, anonymized logs collected with the permission of repository owners, to measure accuracy honestly.
- A ready-made GitHub Action (not in v0.1.0).
- Optional PR comment mode with documented permissions.
- Additional AI providers beyond OpenAI-compatible servers, if there is demand and real testing.
- Custom user rules from YAML (needs a careful security design first).
- Publishing to npm and updating the quick start to `npx`.

Explicitly out of scope for now: dashboards, history storage, automatic fixes or commits, plugins.
