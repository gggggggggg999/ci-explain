# Пост для IT-чатов (Кыргызстан и СНГ)

Публикацию выполняет владелец. Проверьте правила каждого чата про самопиар и рекламу.

Сделал open-source инструмент ci-explain: читает лог упавшей CI-сборки и коротко объясняет, почему она
упала, с точными строками лога как доказательством. Работает офлайн, секреты маскирует, ИИ подключается только
по флагу (и `--show-prompt` показывает, что именно будет отправлено).

Пока это ранняя версия: 34 правила (npm/pnpm/yarn, TypeScript, ESLint, Jest/Vitest, pytest, Docker и др.),
проверена на синтетических логах, шаги разбираются только для GitHub Actions. Если причина не распознана, так и пишет, а не придумывает.

Ставится из исходников: https://github.com/gggggggggg999/ci-explain

Буду благодарен за упавшие логи (обезличенные через `--export-excerpt`, перед отправкой прочитайте файл) и
за идеи, какие ошибки объяснять следующими.
