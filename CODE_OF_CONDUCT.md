# Code of Conduct

We want ci-explain to be a welcoming project for everyone who contributes,
reports issues, or asks questions.

## Expected behavior

- Be respectful and assume good intent.
- Give and accept constructive feedback.
- Focus on what is best for the project and its users.

## Unacceptable behavior

- Harassment, insults, or discrimination of any kind.
- Publishing other people's private information.
- Posting real secrets, tokens, or private logs in issues (see
  [SECURITY.md](SECURITY.md) and [docs/PRIVACY.md](docs/PRIVACY.md)).

## Enforcement

Maintainers may edit or remove comments, issues, and pull requests that
violate this code, and may block repeat offenders. To report a problem, open
a private security advisory or contact the maintainer through the GitHub
profile listed on the repository.
